# ☁ ElytrixParadise — Ивент «Райское место»

Плагин для Minecraft (Spigot / Paper 1.16.5 - 1.20+), создающий всегда активный ивент **«Райское место»** на координатах **X=0, Y=170, Z=0** в мире **world**.

---

## 📁 Куда положить схематику?

Поместите ваш файл схематики по пути:
```text
plugins/ElytrixParadise/schematics/paradise.schem
```
*(Папка `schematics/` создаётся автоматически. Имя файла настраивается в `config.yml` в поле `schematic.file`)*.

---

## 💎 Механика «Осколков Рая»:

1. **Расположение и блоки**:
   - По бокам схематики расположены блоки **Красной глазурованной керамики** (`RED_GLAZED_TERRACOTTA`) — это **Осколки Рая**.
   - Плагин автоматически находит и регистрирует их при вставке схематики.

2. **Информативная голограмма**:
   - Над каждым активным осколком отображается динамическая голограмма (DecentHolograms / встроенная стойка):
     - `✦ Осколок Рая ✦`
     - `● Активен (Добывай киркой)`
     - `Добывай для получения лута и опыта!`
     - `Риск взрыва: X%`

3. **Процесс добычи**:
   - Игроки бьют по осколку любой **киркой**. Сам блок **не ломается**, но с него при каждом ударе вылетают искры, сферы опыта и ценный лут, падающий на землю.
   - Добыча продолжительная: внутренний интервал между ударами составляет ~800 мс.

4. **Риск взрыва и детонация**:
   - С каждым ударом шанс взрыва осколка **увеличивается** (+1.5% за каждый удар).
   - При срабатывании взрыва раздаётся мощный раскат грома и детонация:
     - Взрыв наносит **24.0 чистого урона** в радиусе 5.5 блоков (смертельно для игроков без брони, в железной броне или полу-алмазке) с сильным откидыванием.
     - **Блоки окружения не разрушаются!**

5. **Перезарядка осколка**:
   - После детонации блок мгновенно превращается в **Серую глазированную керамику** (`GRAY_GLAZED_TERRACOTTA`).
   - Голограмма переключается в режим обратного отсчёта на **10 минут** (`Перезарядка: MM:SS`).
   - По истечении 10 минут осколок с эффектом тотема и звоном колоколов снова становится **Красной керамикой** и готов к добыче!

## ☁ Actionbar & Близость к ивенту

- Когда игрок находится рядом с райским островом (в радиусе 45 блоков по горизонтали и на высоте от 150 до 195 блоков), над хотбаром отображается стильный Actionbar:
  - В зоне ивента: `☁ Райское место ✦ Осколков активно: X/Y ✦ Добывай киркой!`
  - Рядом с конкретным осколком: `☁ Райское место | Добывай Осколок! | Риск взрыва: X%`
- Игроки, бегающие внизу по обычной земле (Y=60-70), Actionbar не получают.

## 🧹 Автоматическое удаление при выключении

- При выключении сервера или плагина область схематики автоматически очищается, все голограммы и осколки безопасно удаляются.

## 📜 Команды и права

| Команда | Описание | Право |
|---|---|---|
| `/ep help` | Список доступных команд | `elytrixparadise.use` |
| `/ep tp` | Телепортация в Райское место (X=0, Y=172, Z=0) | `elytrixparadise.tp` |
| `/ep info` | Информация об ивенте и количестве активных осколков | `elytrixparadise.use` |
| `/ep schem` | Инструкция по схематике | `elytrixparadise.use` |
| `/ep reload` | Перезагрузить конфигурацию, лут и сообщения | `elytrixparadise.admin` |
| `/ep paste` | Вставить схематику на X=0, Y=170, Z=0 и активировать осколки | `elytrixparadise.admin` |
| `/ep clear` | Удалить схематику и осколки | `elytrixparadise.admin` |
| `/ep setcenter` | Установить центр ивента | `elytrixparadise.admin` |
| `/ep setspawn` | Установить точку спавна телепортации | `elytrixparadise.admin` |
