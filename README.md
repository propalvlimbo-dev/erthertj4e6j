# ☁ ElytrixCemetery — Ивент «Кладбище»

Плагин для Minecraft (Spigot / Paper 1.16.5 - 1.20+), создающий постоянный атмосферный ивент **«Кладбище»** на координатах **X=0, Y=64, Z=0** (настраивается в `config.yml`).

---

## 🪦 Основные механики:

1. **Раскапываемые могилы (20 шт)**:
   - Игроки раскапывают могилы **лопатой** (любой тип лопаты).
   - После вскапывания открывается сундук с ценным лутом на 15 секунд.
   - По истечении времени яма автоматически закапывается, сундук очищается и запускается перезарядка (30 минут).
   - Индивидуальные голограммы над каждой могилой в прозрачном стиле ElytriX.

2. **Призраки (Allay)**:
   - Летающие призрачные сущности, охраняющие кладбище.
   - Ограничены территорией кладбища (телепортируются обратно при попытке улететь).
   - Защита от дюпа и передачи предметов.
   - 100% дроп **Призрачного осколка** + шанс на редкий лут.
   - Автоматический респавн волны призраков.

3. **Встроенная генерация / Схематика**:
   - Автоматическая процедурная генерация атмосферного кладбища (ограда, входная арка, склеп, надгробия, жуткие деревья) при отсутствии файла схематики.
   - Поддержка внешних WorldEdit/FAWE `.schem` файлов в `plugins/ElytrixCemetery/schematics/cemetery.schem`.

4. **Удобный GUI редактор лута**:
   - `/cemetery edit <graves|ghosts>` — 4-страничный редактор лута в игре.
   - Автоматическое масштабирование шансов выпадения предметов в зависимости от онлайна сервера.

---

## 🛡 Защита региона `elytrix_cemetery` (WorldGuard):

- Автоматически создаётся защищённый регион `elytrix_cemetery`.
- **Флаги**: отключён спавн лишних мобов, запрещены взрывы криперов и TNT, включён PvP.
- **Запрет Fly и GodMode**: при входе в зону ивента режим полёта и бессмертия отключаются.

## 📜 Команды и права

| Команда | Описание | Право |
|---|---|---|
| `/cemetery help` / `/ec help` | Список команд плагина | `elytrixcemetery.use` |
| `/cemetery info` | Информация об ивенте и могилах | `elytrixcemetery.use` |
| `/cemetery tp` | Телепортация на Кладбище | `elytrixcemetery.admin` |
| `/cemetery edit <graves\|ghosts>` | Открыть GUI редактор лута | `elytrixcemetery.admin` |
| `/cemetery reload` | Перезагрузка конфигурации и лута | `elytrixcemetery.admin` |
| `/cemetery paste` | Вставка/генерация кладбища | `elytrixcemetery.admin` |
| `/cemetery clear` | Очистка кладбища и призраков | `elytrixcemetery.admin` |
| `/cemetery setcenter` | Установить центр ивента | `elytrixcemetery.admin` |

## 📊 Плейсхолдеры (PlaceholderAPI):

- `%elytrixcemetery_time%` — Время до ближайшего обновления могил (MM:SS)
- `%elytrixcemetery_active%` — Количество готовых к раскопке могил
- `%elytrixcemetery_total%` — Общее количество могил (20)
- `%elytrixcemetery_ghosts%` — Количество живых призраков
- `%elytrixcemetery_status%` — Статус активности ивента
- `%elytrixcemetery_location%` — Название локации
